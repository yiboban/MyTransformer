# Assignment 02：基础神经网络模块

## 1. 学习目标

手写 Linear、Embedding、RMSNorm、稳定 softmax 和 next-token cross entropy，理解参数布局、广播、数值稳定、autograd 与 dtype/device 传播。

## 2. 生活化直觉与模块位置

Linear 像改变坐标系；Embedding 是按 token id 查字典；RMSNorm 像只调节音量而不减去“平均语调”。这些部件贯穿 embedding、QKV/O、FFN、final norm 与 lm_head。

## 3. 数学公式与逐步推导

无 bias Linear：

$$y=xW^\top,\quad W\in\mathbb{R}^{D_{out}\times D_{in}}$$

RMSNorm 只沿最后一维：

$$\operatorname{RMSNorm}(x)=g\odot x\,(\tfrac1D\sum_i x_i^2+\epsilon)^{-1/2}$$

稳定 softmax 令 $m=\max_i x_i$：

$$p_i=\frac{e^{x_i-m}}{\sum_j e^{x_j-m}}$$

减同一常数不改变比值，却避免大正数 overflow。Cross entropy 用目标索引 gather：

$$\mathcal L=-\frac1N\sum_n\log p_{n,y_n}$$

可复用自己写的稳定 log-sum-exp 思路，但不能调用 `F.cross_entropy`。

## 4. 输入输出 shape

| API | 输入 | 参数 | 输出 |
|---|---|---|---|
| Linear | `[...,Din]` | weight `[Dout,Din]` | `[...,Dout]` |
| Embedding | `[...]` integer | weight `[V,D]` | `[...,D]` |
| RMSNorm | `[...,D]` | weight `[D]` | same |
| softmax | arbitrary | dim | same |
| CE | logits `[...,V]`, targets `[...]` | 无 | scalar |

例：`[2,6] ids → Embedding [2,6,32] → Linear(32,96) [2,6,96]`。

## 5. 精确 API 与参数

签名见 `layers.py`/`functional.py`。`device/dtype` 仅控制浮点参数；token id 必须是整数。`eps` 防止全零向量除零。Linear 无 bias，且 weight 约定与 `F.linear` 一致。

## 6. RMSNorm 与 LayerNorm

LayerNorm 通常先减均值再除标准差，并有 scale/shift；RMSNorm 不中心化，只按均方根缩放，本项目仅有 scale。它计算更简单且保留均值方向，不能用 LayerNorm 冒充。

## 7. 实现限制

学生端禁止 `nn.Linear/F.linear`、`nn.Embedding/F.embedding`、`nn.RMSNorm`、`torch.softmax/F.softmax/F.cross_entropy`。允许底层 `matmul`、索引、`exp`、`log`、`rsqrt`。必须保持梯度图。

## 8. 分步提示

1. Linear 先校验最后一维再做矩阵乘；初始化可用截断正态或按 fan-in 缩放。
2. Embedding 验证整型，然后利用 tensor advanced indexing。
3. RMSNorm 用 `keepdim=True`；需要时在 float32 累积再转回输入 dtype。
4. softmax 先规范化负 dim，再减 max。
5. CE 验证 `logits.shape[:-1] == targets.shape`，gather 目标列再 mean。

## 9. 常见错误

- weight 存成 `[Din,Dout]`，fixture/state_dict 不兼容；
- RMSNorm 沿 sequence 维或减了均值；
- softmax 忽略传入 dim；
- `exp(10000)` 溢出；
- CE 对 class 维也求平均；
- forward 创建 CPU 常数造成 device mismatch。

## 11. 面试题与参考答案

1. 为什么 Linear 权重转置？PyTorch 保存 `[out,in]`，输入右乘其转置。
2. Embedding 本质？对 weight 第一维的可微查表，id 本身无梯度。
3. RMSNorm 与 LayerNorm 差异？前者不减均值，通常无 bias。
4. 为什么减 max 不改 softmax？分子分母同乘 $e^{-m}$。
5. atol/rtol？绝对与相对误差阈值。
6. CE 为什么用 logits 而非先存概率？log-sum-exp 更稳定。
7. targets 为什么不是 one-hot？索引 gather 更省内存。
8. logits 是概率吗？不是，可为任意实数。
