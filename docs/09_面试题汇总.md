# Transformer 面试题汇总

## Tokenization

1. **byte-level BPE 为什么没有 OOV？** 256 个单字节覆盖任意 UTF-8 字节串。
2. **merge rank 与词表最长匹配有何不同？** rank 是训练操作顺序；最长词表项可能不能按合法历史得到。
3. **special token 重叠如何处理？** 同位置 longest match，并保持原子性。

## 数值与归一化

4. **为什么 softmax 减最大值？** 不改比例，同时避免指数 overflow。
5. **RMSNorm 与 LayerNorm？** RMSNorm 不减均值，按均方根缩放，通常参数更少。
6. **为什么浮点不用 `equal`？** 并行归约和运算顺序造成合理末位误差，应使用 atol/rtol。

## RoPE 与 Attention

7. **RoPE 如何表达相对位置？** $R(p)^TR(s)=R(s-p)$。
8. **为什么 Q/K 转而 V 不转？** QK 决定地址相似度，V 是汇总内容。
9. **为什么缩放 sqrt(d_head)？** 未缩放点积方差随 head 维增长，softmax 会饱和。
10. **mask 为什么先于 softmax？** 禁区置负无穷后概率为 0，其余自动归一化。
11. **多头是否重复？** 否；独立 projection 让各 head 学不同子空间。
12. **Q/K/V 语义？** 当前需求、可检索地址、返回内容。

## FFN 与 Block

13. **SwiGLU 为什么三个 Linear？** 两个上投影做 gate×content，一个下投影回 D。
14. **pre-norm 与 post-norm？** norm 在子层前 vs residual 后，梯度路径不同。
15. **residual 为什么重要？** 提供恒等信息和梯度高速路径，让子层学习增量。

## Language Model

16. **logits 是概率吗？** 不是；softmax 后才是。
17. **next-token 标签如何构造？** 输入去最后 token，标签去第一个 token。
18. **如何测试未来泄漏？** 保持前缀、只改后缀，前缀 logits 必须一致。
19. **greedy 与 temperature sampling？** greedy 取 argmax；温度缩放后按分布抽样。
20. **为何不拿完整模型对比 TransformerEncoder？** RoPE、RMSNorm、SwiGLU、pre-norm 与布局均不同，比较没有有效 oracle 意义。

## 口述 shape 题

给 `B=2,T=8,D=32,H=4,V=271`：Q/K/V 是 `[2,4,8,8]`，score 是 `[2,4,8,8]`，合并 head 后 `[2,8,32]`，logits `[2,8,271]`。mask `[8,8]` 可广播到 score。
