# Assignment 00：学习路线与接口总览

## 1. 学习目标与生活化直觉

先统一“箱子标签”。Transformer bug 常不是公式不会，而是把 batch、时间或 feature 轴摆错。把 batch 想成同时处理的几本书，sequence 是每本书的页码，feature 是每页的表示；head 是把同一表示拆给多个不同专长的读者。

## 2. 统一张量约定

全项目 `batch_first=True`：

| 符号 | 含义 | 常见 shape |
|---|---|---|
| B | batch size | `[B,...]` |
| T/Q/K | sequence/query/key length | `[B,T,...]` |
| D | d_model | `[B,T,D]` |
| H | num_heads | `[B,H,T,Dh]` |
| Dh | head dimension = D/H | 最后一维 |
| V | vocabulary size | logits `[B,T,V]` |

shape 流转例：`[2,6] token ids → [2,6,32] embedding → [2,4,6,8] Q/K/V → [2,4,6,6] scores → [2,6,32] attention → [2,6,271] logits`。

## 3. dtype 与 device 传播

模块用构造器的 `device/dtype` 创建参数；forward 不应 `torch.tensor(existing_tensor)` 或 `.cpu()`。整数 token id 通常是 `torch.long`，embedding 输出跟权重 dtype/device 一致。bool mask 是 `torch.bool`，在 score 所在 device 上创建。

## 4. state_dict

`state_dict()` 是参数与持久 buffer 的名字到 tensor 的映射，不保存 Python 源码或优化器。相同 config 的新模型可以 `load_state_dict(..., strict=True)` 恢复输出；RoPE 的派生缓存是否 persistent 可自行选择，但公开状态必须可往返。

## 5. 为什么浮点不能逐位相等

浮点加法不满足结合律；并行归约与 kernel 顺序可能让末位不同。`torch.equal(a,b)` 要求 shape、每个值完全相同；`torch.allclose`/`torch.testing.assert_close` 检查：

$$
|a-b| \le \mathrm{atol} + \mathrm{rtol}|b|
$$

`atol` 处理靠近 0 的绝对误差，`rtol` 处理随量级增长的相对误差。离散 id/mask/merge 用 `equal`，浮点输出用合理 tolerance。

## 6. 所有公开 API

| 模块 | API | 输入 → 输出 |
|---|---|---|
| BPE | `train_bpe` | path → vocab, merges |
| tokenizer | `encode/decode` | str ↔ ids |
| Linear | `forward` | `[...,Din]→[...,Dout]` |
| Embedding | `forward` | `[...]→[...,D]` |
| RMSNorm | `forward` | `[...,D]→[...,D]` |
| RoPE | `forward` | `[B,H,T,Dh]→same` |
| mask | `make_causal_mask` | lengths → `[Q,K] bool` |
| attention | function | Q,K,V → `[B,H,Q,Dv]` |
| MHA/FFN/Block | module | `[B,T,D]→same` |
| LM | `forward` | `[B,T]→[B,T,V]` |

精确参数见各 module 文档与 stub；不要根据本表猜默认值。

## 7. 实现限制与分步提示

先写 shape validation，再写核心公式，最后检查 dtype/device/grad。每完成一项跑对应 stage。不要改测试 tolerance 掩盖 axis 错误，不在 adapter 重写算法。

## 8. 常见错误与失败阅读

- `[B,T,H,Dh]` 忘记 transpose 为 `[B,H,T,Dh]`；
- `view` 前 tensor 非 contiguous，可用 `reshape` 或先 `contiguous`；
- 误把 logits 当 probability；logits 是任意实数，softmax 才是归一化概率；
- next-token 标签未右移：输入 `ids[:,:-1]` 对齐目标 `ids[:,1:]`。

失败时先看测试名，再看 expected/actual shape，然后看首个数值差；`--verbose` 保留原 traceback。

```bash
uv run python -m grader --list
uv run pytest tests/test_primitives.py -q
```

## 9. 面试题与参考答案

1. 为什么 batch first？统一工程约定，减少 transpose 错误。
2. logits 是概率吗？不是；softmax 后才是概率。
3. label shift 怎么做？位置 t 的输入预测 t+1 token。
4. `equal` 与 `allclose`？前者逐值精确，后者带容差。
5. `state_dict` 含什么？参数与持久 buffer，不含 forward 代码。
6. Dh 是什么？`d_model/num_heads`。
7. mask dtype？bool，且本项目 True=允许。
8. 为什么固定 seed？使初始化和随机测试可复现，但不保证所有硬件 bitwise 一致。
