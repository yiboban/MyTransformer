# 常见错误排查

## 先读错误，不先改测试

1. 看测试名描述的行为；2. 找首个 traceback；3. 比 expected/actual shape；4. 打印小 tensor；5. 回到最底层失败 stage。`--verbose` 不会吞掉 pytest 原始错误。

| 症状 | 常见原因 | 优先检查 |
|---|---|---|
| 中文 roundtrip 错 | 按 Unicode 字符训练 | `text.encode("utf-8")` |
| BPE 每次 merge 不同 | tie-break 依赖 dict | 显式 `(-freq,pair)` |
| softmax NaN | 未减 max/全行被 mask | max shift、mask row |
| attention shape 对但数值错 | scale/axis/mask | sqrt(Dh)、dim=-1、pre-softmax |
| 过去 logits 改变 | future leak | lower-triangular allow mask |
| batch=1 过、batch=2 失败 | reshape/transpose 混轴 | `[B,H,T,Dh]` |
| block identity 失败 | residual 漏/加错对象 | 两行固定公式 |
| gradient None | detach/item/重建 tensor | autograd graph |
| state_dict load missing keys | 参数名或注册方式 | ModuleList/Parameter/buffer |
| loss 不降 | label 未右移/学习率 | inputs/targets 对齐 |

## dtype/device

不要在 forward 写裸 `torch.zeros(shape)` 后与 CUDA tensor 运算；用输入的 `new_zeros` 或显式 device。不要把 token id cast 成浮点。mixed precision 时归一化可在 float32 累积，再转回原 dtype。

## 浮点比较

差异只在 1e-7 不代表实现错误；但不要擅自把 tolerance 放大到掩盖公式错误。先看相对量级、float32/float64、运算顺序。离散 id、merge、mask 必须精确相等。

## 快速命令

```bash
uv run python -m grader --stage attention --verbose

uv run ruff check .
```

## 面试自检与答案

1. shape 错先查什么？公开契约和 transpose 点。
2. causal 泄漏最小测试？固定前缀、改变后缀、比较前缀输出。
3. batch independence？同一样本单跑/拼 batch 应一致。
4. masked probability？必须严格为 0。
5. 为何保留 traceback？中文 hint 是分类建议，原始调用栈才给准确位置。
